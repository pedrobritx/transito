Esta página descreve o comportamento observável do código atual, não garante como terceiros tratam dados.

Como o Transito processa uma URL

O código SwiftUI atual processa a URL localmente e a encaminha ao FFmpeg ou WebKit quando necessário. A mídia é gravada no destino escolhido.

Conexões externas

O app acessa o servidor ou a página informada. O instalador opcional de FFmpeg pode baixar arquivos de evermeet.cx. Servidores e instaladores têm suas próprias políticas de privacidade.

Este website

Este site estático não inclui pixels publicitários, scripts externos de análise ou cookies próprios. Ele pode consultar a API do GitHub para escolher um download real. GitHub Pages e destinos externos podem registrar conexões.

Distribuição de software

Builds de desenvolvimento podem não ter assinatura ou notarização. Baixe apenas de fontes confiáveis e examine os alertas do macOS. Nunca desative a segurança global para instalar um build.

Direitos autorais e permissões

Salve apenas conteúdo cujo download seja autorizado. O Transito não contorna DRM nem garante acesso a streams protegidos.

Para relatar um problema, use o GitHub sem publicar URLs privadas, tokens ou cookies.
