01 / TRANSPARENCY

Know the route your data takes.

This page describes the observable behaviour of the current source, not a guarantee of how third-party services treat data.

How Transito processes a URL

The current SwiftUI code processes the entered URL locally and passes it to FFmpeg or WebKit as needed. Media is written to the output path you choose.

External network requests

The app connects to the stream host or web page you enter. Its optional FFmpeg installer requests binary archives from evermeet.cx. Stream hosts and installers have their own privacy practices.

This website

This static site includes no advertising pixels, third-party analytics scripts or site cookies. It can request public release metadata from GitHub's API to select a real downloadable asset. GitHub Pages and third-party destinations may log connections.

Software distribution

Development build artifacts may be unsigned or unnotarized. Download only from trusted sources and review macOS warnings. Never disable macOS security protections globally to install a build.

Copyright and permissions

Only save content you are authorised to download. Transito does not claim to bypass DRM and cannot guarantee access to protected streams.

To report an issue, use GitHub and never post private URLs, access tokens or cookies.
